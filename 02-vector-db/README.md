### Learning objective:
By the end of this lesson, students will be able to load, split, and embed documents to store and query within a vector database. 
 

### About:  
In this lesson, we introduce the concept of vector databases and apply them to question and answer chains. 

### Prerequisites:
- Introduction to LangChain
- Advanced Prompt Development Module
